# gap-diagnosis · 破局诊断

## 用途
严格实现仓库中的 diagnose Skill。基于用户自述、上下文记忆和用户画像，完成五维差距扫描，不画饼，不平均主义。

## 输入
- messages：用户与助手的对话记录，可选；
- context：会话记忆摘要，可选；
- profile：长期用户画像，可选。

## 固定五维
1. 技术栈
2. 实习经历
3. 项目经历
4. 算法能力
5. 信息差

每个维度输出 current（0-100）、target（0-100）、gap（target-current）。

## 输出
- reply：2-4 句口语化中文，先共情双非处境，再给一个本周可做的小行动；
- radar：五个维度数组；
- recommendedRoles：2-3 个岗位，字段为 role、matchScore、reason。

## 硬性规则
- 维度名称不得更改，不得替换为其他框架；
- 评分必须能追溯到用户自述或画像事实；
- 双非学生通常信息差和实习经历缺口较大，但仍需按实际信息打分，不做平均分配；
- matchScore 要有区分度；
- 每条推荐理由必须说明“为什么适合这位双非学生”，并给出一个具体入手动作；
- 不虚构岗位、企业、薪资或经历；
- 只输出符合契约的结构化内容，不添加无关长篇解释。

## 验收标准
- radar 恰好包含上述五维；
- 每个维度都有 current、target、gap；
- recommendedRoles 为 2-3 条且理由具体；
- 输出可直接作为 plan 和 info 的输入。
