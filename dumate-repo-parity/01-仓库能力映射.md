## 路由规则

- 用户描述背景：profile-intake
- 用户问能力差距：diagnose
- 用户要行动计划：plan
- 用户要练习或模拟面试：practice
- 用户找机会：info → evidence-check → active-job-verifier
- 用户改简历：resume 或 package
- 用户准备面试：interview
- 用户拿 JD 评估匹配：match
- 用户上传学习资料：course
- 用户做职业测评：assessment
- 用户要完整闭环：profile-intake → diagnose → info/evidence → plan → practice → package

## 输出原则

- 所有模型 Skill 只输出符合仓库契约的字段。
- 信息类 Skill 不得直接断言“双非友好”。
- 友好等级由证据规则计算。
- 无证据时返回空结果或 unverified。
- 简历类 Skill 不得新增不存在的经历和数据。
