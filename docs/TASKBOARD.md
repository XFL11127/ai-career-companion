## 移动卡片的规则

1. 待办 → 进行中：认领时移动，填负责人 + 分支。
2. 进行中 → 待审核：PR 合入 `基础骨架` 后移动。
3. 待审核 → 完成：队长/评委验收通过后，移至 `ROADMAP.md` 已交付或删除本卡。
4. 每次移动 **commit 进 `基础骨架`**，队友 pull 即见。
