## 五、仍需人工确认

1. 在 Chrome / Edge 中点击“打印 / 导出 PDF”，确认浏览器打印窗口可保存 PDF。
2. 在 Chrome / Edge 中点击“导出 DOCX”，用 Word / WPS 打开并检查中文、标题、段落。
3. 使用真实且复杂的个人简历验证 ATS 建议质量，但不得上传敏感简历给不可信环境。
4. 对扫描版 PDF 单独验证错误提示；当前版本不做 OCR。
