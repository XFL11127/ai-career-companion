| 命令 | 通过标准 |

## 三、M1 智能简历工坊

**入口**：`/resume`

准备一份 PDF 或 DOCX 简历，以及一个真实岗位 JD。

操作：

1. 上传简历，确认页面显示文件名和提取字数。
2. 填写目标岗位，粘贴 JD。
3. 点击“开始优化与评分”。
4. 检查综合评价、ATS 可解析度、缺失关键词、优势、四维评分、改写建议和优化稿。
5. 点击“复制优化稿”。
6. 点击“打印 / 导出 PDF”，在浏览器打印窗口选择“另存为 PDF”。
7. 点击“导出 DOCX”，用 Word/WPS 打开导出的文件。

通过标准：

- [ ] 简历文本成功提取，不需要手工补录。
- [ ] 出现 0-100 的综合分与 ATS 分。
- [ ] 缺失关键词、改写前后文本、优化稿均有内容。
- [ ] 生成的建议未虚构公司、学历、证书或数字。
- [ ] PDF 可打开，中文不乱码。
- [ ] DOCX 可打开，标题和段落顺序正确。
- [ ] 旧版 `.doc` 明确报错并提示另存为 `.docx`；扫描版 PDF 无文本时给出明确提示。

## 四、M2 模拟面试舱

**入口**：`/interview`

操作：

1. 填写目标岗位。
2. 上传或粘贴简历，粘贴岗位 JD。
3. 选择“综合面”和“中文”。
4. 点击“生成本轮面试”。
5. 任选 2-3 题填写答案，保留至少一题不答。
6. 点击“提交回答并评分”。

通过标准：

- [ ] 第一轮生成 4-6 道有岗位针对性的问题。
- [ ] 每题显示考察意图、STAR 提示和参考答题框架。
- [ ] 未提交回答时，不出现伪造的评分。
- [ ] 提交回答后出现清晰度、结构、相关性、深度和总分。
- [ ] 反馈能指出具体回答问题，而不是只给空泛鼓励。
- [ ] 页面统计“已完成 X / Y 题”，未答题不影响已答内容。
- [ ] 支持中文、英文、中英双语三个选项。

## 五、M3 岗位匹配雷达

**入口**：`/match`

准备一份简历和一个真实 JD。

操作：

1. 上传或粘贴简历。
2. 粘贴 JD，填写期望地点、行业和职业目标。
3. 点击“生成匹配报告”。
4. 检查五维评分、权重、总分、建议、缺失词、风险和行动。
5. 若结果为“建议投递”，点击“进入人工投递清单”。

通过标准：

- [ ] 技能、经验、地域、行业、职业轨迹五项都显示分数、权重和理由。
- [ ] 权重合计为 100，总分与五维结果方向一致。
- [ ] 信息不足或明显缺项时显示“补齐后再投”，不是盲目 recommend。
- [ ] 页面明确说明系统不会自动登录、自动填写或批量提交。
- [ ] 岗位关键词缺失有可执行补强项。
- [ ] `caution` / `avoid` 状态不显示“进入人工投递清单”。

## 六、M4 课程学习助手

**入口**：`/course`

分别用一个 PDF、一个 DOCX 和一个 PPTX 测试。

操作：

1. 上传资料，确认文件名和字数。
2. 填写学习目标和当前水平。
3. 点击“生成学习包”。
4. 检查知识总览、关键概念、主动回忆卡、常见误区、学习计划和小测。
5. 点击卡片的“翻面”和上一张/下一张。
6. 回答单选题，点击“查看答案”。

通过标准：

- [ ] PDF、DOCX、PPTX 至少一种真实文件成功提取文本。
- [ ] 概念解释包含定义、例子和“为什么重要”。
- [ ] 抽认卡可以翻面、切换。
- [ ] 小测选项、答案和解析完整。
- [ ] 学习计划按多日拆分，任务可执行。
- [ ] 资料未提及的内容不会被编造成确定事实。
- [ ] 扫描版 PDF、加密文件或旧版 `.ppt/.doc` 有明确错误提示。

## 七、M5 自我认知测评

**入口**：`/assessment`

操作：

1. 逐题完成 18 道 1-5 分题。
2. 检查未完成时按钮是否禁用。
3. 全部完成后点击“生成我的职业探索画像”。
4. 检查画像标题、代码、维度、优势、待验证假设、职业方向和行动计划。

通过标准：

- [ ] 完成 18 题后按钮才可点击。
- [ ] 页面明确显示“不是心理诊断，不替代职业咨询”。
- [ ] 维度分数与作答方向一致，不出现与作答相反的结论。
- [ ] 推荐职业提供 fitScore、匹配理由和下一步验证动作。
- [ ] 行动计划能在 2-4 周内执行。
- [ ] 刷新后本地缓存能恢复最近一次结果。

## 八、A1 人工门控投递清单

**入口**：`/apply`

操作：

1. 添加公司、岗位、岗位链接、匹配分和备注。
2. 分别测试 50 分、70 分、85 分三个岗位。
3. 切换“待核对 / 待人工投递 / 已投递 / 已回复 / 已结束”状态。
4. 删除一条记录。
5. 刷新页面确认剩余记录仍在。
6. 打开岗位链接确认只跳转外部页面，不发送申请。

通过标准：

- [ ] 匹配分低于门槛时状态为“待核对”。
- [ ] 匹配分达到门槛时状态为“待人工投递”。
- [ ] 所有状态修改刷新后仍保留。
- [ ] 删除后只删除目标记录。
- [ ] 页面明确显示不自动登录、不自动填写、不批量提交。
- [ ] 浏览器 Network 中没有向 BOSS / 智联 / 猎聘发送申请请求。

## 十一、已知边界

- 扫描版 PDF 不做 OCR；没有文本层时必须提示用户改用可复制文本版本。
- 旧版 `.doc` / `.ppt` 不支持，需另存为 `.docx` / `.pptx`。
- PDF 导出依赖浏览器“打印为 PDF”，不是服务端生成 PDF。
- AI 输出仍需人工核对事实，尤其是数字、时间和职责。
- A1 是人工门控骨架，不是自动海投器。
- M5 是职业探索工具，不是经过心理测量学验证的 MBTI/霍兰德/VIA 正式量表。
- 无 API Key 或额度耗尽时会回退 stub；stub 只用于链路测试。
