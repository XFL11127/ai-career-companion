## 一、分支策略（已定）

| 项 | 决策 |
|---|---|

## 二、迭代循环（治"做完基础功能就停滞"）

不是瀑布式"全做完"，而是**永不枯竭的循环**：

```
补齐计划书缺口 ──▶ 打磨稳定 ──▶ 答辩可演示 ──▶ 内测循环（可多次）──┐
   ▲                                                                  │
   └──────────────────────────────────────────────────────────────────┘
```

每个循环结束即进入下一个，永远有"下一步"。
