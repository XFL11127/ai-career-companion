# 三阶段成长计划（career-plan-306090 输出）

> 输入：profile-intake 画像 + gap-diagnosis 五维（技术栈35 / 实习10 / 项目45 / 算法30 / 信息差40）。每周 4 天可投入，目标杭州/上海数据分析或数据运营实习。优先补最大缺口：实习经历（gap 60）与技能验证（技术栈 gap 40）。

## 计划解读（reply）

你现在最大的差距不是能力，而是"简历上没有可验证的数字"和"还没开始投"。所以前 30 天的性价比之王只有一件事：把「食堂消费分析」做出量化结果（处理了多少条数据、发现了哪个消费规律），它同时补技术栈、项目经历和简历，一箭三雕。3 个月实习窗口很真实，按下面三个阶段走，第 61-90 天你就能带着完整简历去冲刺。
